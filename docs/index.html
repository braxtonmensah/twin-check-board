twin-check board

Near-twin overlap between published train and test splits, measured weekly in GitHub Actions by braxtonmensah/twin-check@v1 (commit a851bc0db5ee) as a remote action. Twin: a test row whose closest training row has a Levenshtein ratio of 0.80 or above. Exact: verbatim match. Both are percent of test rows.

These are overlap rates, not score inflation. Nothing is retrained here, so a rate does not say how much any reported score is overstated. No issue was filed on any benchmark by this board. Data is fetched from each benchmark's own URL at run time, checked against a pinned sha256, and not redistributed.
